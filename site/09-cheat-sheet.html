Appendix — Quick-Reference Cheat Sheet

One page to keep open in a second window while you design.

Cover dimensions formula (print, with bleed)

wrap width  = (trim width  x 2) + spine width + 0.25"
wrap height =  trim height + 0.25"
pixels = inches x 300

Spine width multipliers (inches per page)

Interior Paper Multiplier
B&W White 0.002252
B&W Cream 0.0025
Standard color White 0.002347
Premium color — use KDP template

Example: 240 pages, b&w on white → 240 x 0.002252 = 0.54".

Common trim sizes (with bleed, height; width adds spine)

Trim + bleed each dim
5 x 8 5.25 x 8.25
5.5 x 8.5 5.75 x 8.75
6 x 9 6.25 x 9.25

Ebook cover

  • 1600 x 2560 px minimum, recommend 2000 x 3125 px+
  • JPG, sRGB, front cover only (no bleed/spine/back)

Safe zones (print)

  • Bleed: art extends 0.125" past trim on all four sides
  • Text keep-out: 0.25" minimum from trim (0.375" is comfier)
  • Barcode zone: bottom-right of back cover, ~2" x 1.2", keep clean
  • Spine text: only at 100+ pages; pad 0.0625"+ above/below text

Type rules

  • 2 fonts max: display title font + worker font
  • Hierarchy: title > author > everything else
  • Tracked-out caps, one effect per word, no text edge-to-edge

Genre speed-read

  • Romance: warm, elegant serif/script, faces & mood
  • Thriller: high contrast, bold sans, silhouette, red accent
  • Fantasy: ornate logotype serif, epic scene or map
  • Sci-fi: geometric sans, planets/ships/grids, future-clean
  • Horror: one uncanny object, distressed serif, restraint
  • Self-help/business: huge humanist sans, simple metaphor, air
  • Cookbook: big friendly serif, full-bleed food photo
